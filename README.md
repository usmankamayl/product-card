# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание: верстка верхней части карточки товара интернет-магазина
[Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun) — изображение,
название, категория, выбор фасовки, артикул, цена/старая цена, кнопка
«В корзину» и короткое описание.
Посмотреть страницу - https://usmankamayl.github.io/product-card/
## Запуск

Проект не требует сборки и зависимостей — это статичные HTML/CSS/JS.

1. Скачайте/склонируйте репозиторий.
2. Откройте `index.html` в браузере (двойной клик или
   `open index.html` / перетащить файл в браузер).

Либо поднимите любой локальный статик-сервер из папки проекта, например:

```bash
npx serve .
# или
python3 -m http.server 8080
```

и откройте `http://localhost:PORT`.


## Структура проекта

```
teaboom-product-card/
├── index.html        — разметка карточки товара
├── css/
│   └── style.css      — стили (адаптив, состояния, переменные)
```

## Что реализовано

- Семантическая разметка: `<article>`, `<fieldset>`/`<legend>` для
  выбора фасовки, хлебные крошки как `<nav>` со списком.
- 4 фасовки (100 г / 500 г / 1000 г / 5000 г) с собственными артикулом,
  ценой и старой ценой — данные лежат в объекте `PRODUCT.variants`
  в `js/script.js`.
- При переключении фасовки скриптом обновляются: цена, старая цена
  (скрывается, если скидки нет), артикул и визуально выбранное
  состояние фасовки.
- Кнопка «В корзину» имеет обычное состояние, состояние наведения и
  кратковременное состояние «Добавлено» с тост-уведомлением внизу
  экрана. Реальная корзина не подключена.
- Блок с кратким описанием чая и таблицей характеристик
  (заваривание/регион/хранение).
- Адаптивная раскладка на CSS Grid/Flexbox, проверена на 1440 / 768 / 375 px:
  на десктопе — две колонки (галерея слева, инфо справа) с «прилипающей»
  галереей; на планшете колонки сужаются; на мобильном — одна колонка,
  фасовки и факты о чае переносятся построчно.

## Технологии

Чистые HTML5 / CSS3 (переменные, Grid, Flexbox, медиазапросы) и
JavaScript (ES5+, без фреймворков и сборщиков).
